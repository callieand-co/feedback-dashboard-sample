01 · Conceptual framework

Three power-user archetypes.

Any user can hold one or more tags. Each archetype comes from a different product-led growth hypothesis — storage depth, value delivery, and usage cadence — so the instrumentation plan covers all three.

Volume Storage depth
100+ total saves AND saves in last 7 days AND 3+ folders
Holding a lot of context in the tool signals loyalty — these users have the most to lose if they walk away.
18users tagged this cycle (7.3% of active)
Synthesis Value delivery
5+ insights generated AND 1+ insight edited AND 2+ folders in use
These users are getting the core product promise — "protect the human part of strategy" — and interacting with the synthesis rather than consuming it passively.
12users tagged (4.9% of active)
Habit Usage cadence
Logged in 5+ of last 7 days AND 1+ save / week for 4 consecutive weeks
The strongest leading indicator of retention into a paid tier. Habit means DC is a daily-use tool — the behavioral pattern paid conversion depends on.
9users tagged (3.6% of active)

04 · Open with the technical team

Feasibility questions to resolve.

Questions that determine whether specific signals can be instrumented as designed. Flagged here so the tactical plan above stays honest about what's confirmed vs. pending.

01
Can we distinguish an edit that replaced the entire AI summary from one that only edited part of it? Matters for measuring "AI trust" signals.
Engineering
02
Chrome extension: can we detect installs vs. uninstalls, or only active sessions? Determines whether "extension installed" is a clean activation milestone.
Engineering
03
Can we tie Slack activity back to a HubSpot user (email match or another ID)? Required to cross-reference community engagement with in-app behavior.
Engineering + Ops
04
How long does the system retain individual user events before deletion? Need ≥ 90 days to run 60-/90-day cohort comparisons.
Engineering
05
How do we populate testimonials / comments, and can we pipe Slack insights in? Timing questions for referral links as well.
